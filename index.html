如何让配置在 Codex 插件里生效

  1. 本页保存后点 导出 diy.json，覆盖到插件状态目录；或复制 CLI 在 PowerShell 执行。
  2. 推荐路径：C:\Users\Administrator\.codex\skills\astra-command-center\.astra-luna-state\diy.json
  3. Windows 文本框对话框：powershell -File ...\astra-luna.ps1 diy-settings
  4. 连通验证：diy-test · 模型列表：diy-models
  5. 会话内命令：重启 Codex 后输入 /astra-Diy

说明：Codex「插件管理」界面本身不渲染本地插件的自定义表单。本页是插件的图形设置入口，可浏览器打开，也可挂到插件 assets 供预览；真正写入磁盘请用「导出 diy.json」或 CLI。
